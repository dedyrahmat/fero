# Using Fero

- Open **Settings** from the sidebar or with Command-comma on macOS. In **Downloads**, choose the default save folder, whether to review magnet files before adding, and whether transfers start downloading or stay paused after adding. To type a folder path, enter it and select **Save Folder**. Under **Appearance**, choose System, Light, or Dark, a color palette, row spacing, and **Reduce motion**. New libraries use Harbor Current; choose Ember for the original warm palette. The LAN page follows the browser’s reduced-motion preference.
- Toggle **Focus mode** beside the Fero mark to collapse the sidebar into an icon rail. The filters and Settings remain available, and Fero remembers the sidebar state.
- Drop a `.torrent` onto Fero or choose **Add Torrent** to browse for one. For a magnet, paste the link and choose **Get File List**. Click a filename to preview its full save path, use the checkboxes to choose files, then choose or type an existing download folder. The selected count, download size, and path update as you make changes. Use **Start immediately** to add a magnet before its file list is available.
- Open a transfer’s **Files** tab in the inspector to see which files are selected or skipped.
- Open **Settings → Automation & startup → Watched folders** and select the folders you want Fero to scan. Fero imports `.torrent` files directly inside those folders using the default save folder and **Keep paused** setting. It leaves the source files in place and remembers processed torrents across restarts, including after removal from the library.
- Open **Settings → Automation & startup → RSS subscriptions** to add an RSS or Atom URL. Enter comma-separated include and exclude terms to match titles without regard to case. A title must match at least one include term when the include list has entries. Any exclude match skips it. **Preview Matches** fetches the feed without adding transfers. Saved feeds are checked at startup and every five minutes. Fero accepts magnets and torrent attachments, applies your download defaults, and remembers processed entries after restart.
- In **Settings → Downloads → Bandwidth schedule**, enter a daily start and end time in local time. The scheduled speed caps override the normal library caps during that window. Set an earlier end time to run past midnight.
- Close the window to keep Fero running. Use **Open Fero** or **Quit Fero** from the menu-bar or tray menu. **Settings → Automation & startup → Background** lets you opt in to launching at sign-in. On Windows and Linux, closing minimizes the window to keep GPUI’s event loop running. Linux tray controls require a StatusNotifier-compatible desktop tray.
- In **Settings → Network & remote access → LAN access**, choose a private IP address and port on this computer. Provide absolute paths to a PEM certificate chain and its matching PEM private key. The certificate needs the selected IP as a subject alternative name and must chain to a CA trusted by the phone or browser. Open the displayed HTTPS address and sign in as `fero` with the generated password. Copy the password when it is shown. Saving this form again generates a new password. Browser adds use the default download folder and start-paused setting.

For the installed version, credits, and bundled license notices, open **Settings → About Fero**. On macOS you can also choose **Fero → About Fero**. The LAN page has an **About Fero** section at the bottom.
